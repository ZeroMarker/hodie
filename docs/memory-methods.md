## 记忆系统

新词必须经过加工才能从工作记忆进入长时记忆,而主动提取比重复阅读更能决定长期保留。

- **多重存储模型**:感觉记忆 → 工作记忆 → 长时记忆。工作记忆容量小(经典说法 7±2,后续研究认为约 4 个组块)。
- **加工深度(Craik & Lockhart)**:对意义和联系做深加工,比对字形做浅加工记得牢。
- **遗忘曲线(Ebbinghaus)**:新学内容遗忘很快,每次成功提取后遗忘速度会变慢,这是间隔重复的理论基础。
- **巩固与睡眠**:睡眠有助于巩固刚学的内容,晚上学、次日早晨复习是合理的节奏。
- **干扰**:相似的词放在一起学会互相干扰。例如 affect 和 effect,或同一主题的大量近义词在同一天学,混淆率会升高。

## 记忆方法的证据强度

Dunlosky 等 2013 年的综述把常见学习技巧按证据强度排序;提取练习和分散练习证据最强,重读和划线最弱。

| 方法 | 证据 | 在应用里的落点 |
| --- | --- | --- |
| 提取练习(自测) | 高 | 拼写、听写、填空,别只做看词选义 |
| 分散练习(间隔重复) | 高 | SRS 调度,SM-2 到 FSRS |
| 交错练习 | 中 | 复习队列里混排不同类型的词和题型 |
| 精细询问(为什么) | 中 | 词源讲解、造句 |
| 关键词法(助记联想) | 中,对外语词汇有效,对抽象词差 | 为具体名词提供图像联想 |
| 重读、划线 | 低 | 不作为主要练习形式 |

几条实践上有用的结论:

- **双重编码**:词加图像比纯文字记得牢,对具体名词尤其有效。
- **语境中学习**:句子里学能同时建立搭配和用法,比单词表保留得更好。
- **生成效应**:自己想出、写出的内容比被动看到的记得更牢。
- **理想间隔**:间隔应随保留目标变长。目标保留一周,间隔约一到两天;目标保留一年,间隔要拉长到数周以上。FSRS 根据每个用户的作答数据拟合这一点。
