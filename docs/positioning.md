# 产品定位

2026-10-16

目标人群定为应试学习者,产品定位为长期学习:以考试作为入口和阶段目标,但不做考前突击工具,学习节奏按长期记忆来安排。

## 目标人群

主要是备考英语的中文母语学习者,按考试分为三类:

| 人群 | 词书 | 典型周期 |
| --- | --- | --- |
| 大学生 | CET-4、CET-6 | 一学期到一年 |
| 考研学生 | 考研 | 半年到一年 |
| 出国考试 | 雅思、托福、GRE | 三个月到一年 |

中考、高考词书保留,作为基础不足的用户的起点;NGSL 留给没有考试目标的用户。

## 核心卖点

- **记得住**:FSRS 按遗忘规律安排复习,考完不忘;进度以「已掌握」(稳定性 ≥ 21 天)计,不以「背过」计。
- **一条长期路线**:一本词书学完,自动衔接下一本(如 CET-4 → CET-6 → 考研或雅思),已掌握的词不再重学。
- **少而准**:词汇量测试跳过已会的词,每天 15 分钟左右,按词频先学高频词。

## 「应试」和「长期」怎么兼顾

两者的冲突主要在节奏:考生希望考前把词书过完,长期记忆要求分散学习。规则如下:

1. **考试日期只用于给建议,不改调度**:用户可填考试日期,系统按剩余词数和天数估算每日新词数,给出建议值和预计完成日期;超过自适应上限(20 个)时提示「按当前日期学不完,建议优先高频词」,不放开上限,也不压缩复习间隔。
2. **优先级随考试临近调整**:离考试不到 30 天时,新词只从该词书中词频最高的未学部分取,剩余的词留到考后继续学。
3. **考后不清零**:考试日期过后,提示用户选择下一本词书,已有卡片照常复习。
4. **不做突击模式**:不提供「一天背 200 词」之类的模式,也不提供考前冲刺清单。

## 对功能的影响

| 方面 | 调整 |
| --- | --- |
| 注册引导 | 先选考试和考试日期,再做词汇量测试;默认词书按考试选,不再默认 NGSL |
| 题型 | 在 L1 到 L4 之外增加应试题型:英译中选择、选词填空、近义词辨析(对应考试词汇题的形式);不使用真题原文,避免版权问题 |
| 例句 | 优先展示更书面的例句;听说部分对雅思、托福用户更重要,AI 口语对话按考试口语话题设计场景 |
| 统计 | 增加「本词书已掌握 x / 总数」和预计完成日期 |
| 指标 | 7 日留存和日均学习时长不变;另加 30 日留存,以及考试日期后仍继续学习的用户比例,用来衡量「长期学习」是否成立 |
